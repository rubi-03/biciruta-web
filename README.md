# BiciRuta · Web

Página web de BiciRuta S.L., tienda de bicicletas.

## Estructura

```
biciruta-web/
├── index.html        → estructura y contenido
├── css/estilos.css   → estilos
├── js/app.js         → comportamiento
├── img/logo_biciruta.png
├── README.md
└── .gitignore
```

## Cómo verla

1.  Abrir la carpeta `biciruta-web` en VS Code.
2.  Abrir `index.html`.
3.  Pulsar **Go Live** (extensión Live Server).
